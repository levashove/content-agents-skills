# Каталог Unicode-порчи: кодовые точки, статусы, замены

Справочник к скиллу Unicode-гигиены. Категории делятся на **блокирующие**
(невидимы, легитимного применения в прозе нет — правятся без обсуждения) и
**advisory** (есть легитимные случаи — решает автор/редактор).

## 1. Zero-width и невидимые символы — блокирующие

Удалить (заменить на пустоту). След LLM-вывода и копипаста; ломают поиск,
diff, якоря.

| Код | Имя | Примечание |
|-----|-----|-----------|
| U+200B | ZERO WIDTH SPACE (ZWSP) | самый частый артефакт |
| U+200C | ZERO WIDTH NON-JOINER (ZWNJ) | |
| U+2060 | WORD JOINER | |
| U+00AD | SOFT HYPHEN | невидимый перенос — рвёт слова при поиске |
| U+200E | LEFT-TO-RIGHT MARK (LRM) | |
| U+200F | RIGHT-TO-LEFT MARK (RLM) | |
| U+2061 | FUNCTION APPLICATION | |
| U+2062 | INVISIBLE TIMES | |
| U+2063 | INVISIBLE SEPARATOR | |
| U+2064 | INVISIBLE PLUS | |

**Исключение:** U+200D (ZWJ) и U+FE0F (VS-16) **сохраняются** — они склеивают
эмодзи-кластеры (семья 👨‍👩‍👧, флаги, оттенки кожи). Удалять их можно только вне
эмодзи-последовательностей.

## 2. BOM — блокирующий

| Код | Имя | Правка |
|-----|-----|--------|
| U+FEFF | BYTE ORDER MARK / ZWNBSP | удалить; файлы хранятся в UTF-8 без BOM |

BOM в начале файла — артефакт сохранения; U+FEFF в середине текста — тот же
невидимый символ (ZWNBSP), порча.

## 3. Bidi-контролы — блокирующие

Удалить. Невидимое управление направлением текста; в русской/английской
прозе не встречаются. Известный вектор атаки Trojan Source: текст на экране
отображается не в том порядке, в каком реально записан.

| Код | Имя |
|-----|-----|
| U+202A | LEFT-TO-RIGHT EMBEDDING (LRE) |
| U+202B | RIGHT-TO-LEFT EMBEDDING (RLE) |
| U+202C | POP DIRECTIONAL FORMATTING (PDF) |
| U+202D | LEFT-TO-RIGHT OVERRIDE (LRO) |
| U+202E | RIGHT-TO-LEFT OVERRIDE (RLO) |
| U+2066 | LEFT-TO-RIGHT ISOLATE (LRI) |
| U+2067 | RIGHT-TO-LEFT ISOLATE (RLI) |
| U+2068 | FIRST STRONG ISOLATE (FSI) |
| U+2069 | POP DIRECTIONAL ISOLATE (PDI) |
| U+061C | ARABIC LETTER MARK (ALM) |

## 4. Tag characters — блокирующие

| Диапазон | Имя | Правка |
|----------|-----|--------|
| U+E0001–E007F | TAG CHARACTERS | удалить весь диапазон |

Невидимый «дублирующий алфавит» ASCII: каждой латинской букве соответствует
невидимый tag-символ. Известный канал скрытого текста в LLM-выводе (ASCII
smuggling) — в тексте может быть «зашита» невидимая строка. Легитимное
применение одно и узкое (эмодзи-флаги регионов вроде 🏴󠁧󠁢󠁳󠁣󠁴󠁿) — вне
эмодзи-последовательности диапазон удаляется целиком.

## 5. Private Use Area — блокирующие

| Диапазон | Имя | Правка |
|----------|-----|--------|
| U+E000–F8FF | PRIVATE USE AREA | удалить; цитату/ссылку восстановить без обёртки |

Кодовые точки без стандартного значения — у каждого шрифта или платформы своё.
В LLM-выводе это обёртки цитат при стриминге веб-поиска (U+E200/E201/E202:
невидимы, переживают копипаст, человек их не печатает), в копипасте из
приложений — «квадратики» иконочных шрифтов и логотип платформы U+F8FF.
Эмодзи вне этого диапазона и не затрагиваются. Легитимного применения в
прозе нет — диапазон удаляется целиком.

## 6. Line/paragraph separators — блокирующие

| Код | Имя | Правка |
|-----|-----|--------|
| U+2028 | LINE SEPARATOR | заменить на обычный перенос строки |
| U+2029 | PARAGRAPH SEPARATOR | заменить на обычный перенос строки |

Выглядят как обычный перенос, но ломают JS-встраивание и вёрстку CMS.

## 7. Экзотические пробелы — advisory

Заменить на обычный пробел (или NBSP, если в этом месте нужна
неразрывность). Визуально неотличимы от пробела; почти всегда — след
копипаста из вёрстки или LLM-вывода. Advisory: в редких случаях это
осознанная тонкая типографика.

| Код | Имя | Примечание |
|-----|-----|-----------|
| U+202F | NARROW NO-BREAK SPACE | **характерный след вывода ChatGPT** |
| U+2000 | EN QUAD | |
| U+2001 | EM QUAD | |
| U+2002 | EN SPACE | |
| U+2003 | EM SPACE | |
| U+2004 | THREE-PER-EM SPACE | |
| U+2005 | FOUR-PER-EM SPACE | |
| U+2006 | SIX-PER-EM SPACE | |
| U+2007 | FIGURE SPACE | |
| U+2008 | PUNCTUATION SPACE | |
| U+2009 | THIN SPACE | иногда — осознанная типографика разрядов |
| U+200A | HAIR SPACE | |
| U+205F | MEDIUM MATHEMATICAL SPACE | |
| U+1680 | OGHAM SPACE MARK | |
| U+3000 | IDEOGRAPHIC SPACE | след копипаста из CJK-вёрстки |

**Не входит в категорию:** U+00A0 (NO-BREAK SPACE, NBSP) — легитимная
русская типографика, см. раздел 9.

## 8. Гомоглифы — advisory

Смешение кириллицы и латиницы в одном слове: буква-двойник выглядит
идентично, но это другая кодовая точка. Слово становится ненаходимым
поиском, ломается SEO и копипаст.

Карта двойников (латиница ↔ кириллица):

| Латиница | Кириллица | | Латиница | Кириллица |
|----------|-----------|-|----------|-----------|
| a | а | | A | А |
| c | с | | B | В |
| e | е | | C | С |
| o | о | | E | Е |
| p | р | | H | Н |
| x | х | | K | К |
| y | у | | M | М |
| | | | O | О |
| | | | P | Р |
| | | | T | Т |
| | | | X | Х |
| | | | Y | У |

Правило разбора: подмена-двойник — это **1–2 чужие буквы внутри слова**
(`Сloud` с кириллической «С», `облаkо`, `caталог`). Если «чужой» алфавит —
цельная морфема из 3+ букв, это не подмена, а легитимный композит:

- бренды: `СберCloud`, `МWS`;
- транслит-склонения: `Robом`, `partам`;
- римские цифры: `АгроXXI`;
- дефисные композиты с односкриптовыми сегментами: `SEO-статья`, `IP-адрес`,
  `ML-инструменты` — каждый сегмент чистый, порчи нет.

Правка: привести слово к одному алфавиту (двойник → буква алфавита
большинства). Зоны кода, URL и markdown-ссылок не сканируются.

## 9. Mojibake — advisory

Кириллица или типографская пунктуация, перекодированная через CP1252.
Сигнатуры (в нормальном русском тексте не встречаются):

| Последовательность | Что это было |
|--------------------|--------------|
| пары `Ð?` / `Ñ?` подряд (`Ð¾Ð±Ð»Ð°ÐºÐ¾`) | кириллица UTF-8, прочитанная как CP1252 |
| `â€”` | длинное тире (—) |
| `â€™` | апостроф (') |
| `â€œ` / `â€` | кавычки (" ") |
| `â€¦` | многоточие (…) |

Правка: восстановить исходный символ или перекодировать текст в UTF-8.

## 10. NBSP-типографика — advisory (обратный сигнал)

Единственная категория «символа не хватает», а не «символ лишний».
Неразрывный пробел (U+00A0) **ставится**:

- после однобуквенных предлогов и союзов: `в облаке`, `и сервисы`;
- между числом и единицей: `5 ГБ`, `100 ₽` (процент пишется слитно — `50%`, без NBSP),
  `10 тыс.`, `№ 5`.

Это рекомендация типографики, не порча — применяется по решению редактора.

## 11. Сводка легитимных исключений

| Что | Почему не трогаем |
|-----|-------------------|
| ZWJ (U+200D), VS-16 (U+FE0F) в эмодзи | склейка эмодзи-кластеров |
| Tag characters внутри эмодзи-флагов | часть валидной последовательности |
| NBSP (U+00A0) | легитимная русская типографика |
| Смешанный скрипт: бренды, транслит, римские цифры, дефисные композиты | не подмена-двойник |
| Гомоглифы/пробелы в коде, URL, markdown-ссылках | технические зоны — не проза |
