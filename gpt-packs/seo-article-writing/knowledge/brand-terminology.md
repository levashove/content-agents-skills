# Терминология: дополнения для SEO-статей

Дополняет `common-brand-terminology.md`.

## Продуктовые названия — SEO-контекст

| Правильно | Неправильно |
|-----------|-------------|
| Cloud Servers | Виртуалки, облачные серверы (в контексте продукта) |
| Object Storage | Cloud Storage, Объектное хранилище (как имя продукта) |
| Managed Containers | Managed Kubernetes, Cloud Containers (прежние имена — только в цитатах и архивных ссылках), Облачные контейнеры (как имя продукта); полная форма при первом упоминании — с именем платформы, по `canonical` продуктового скилла (`common/brand-terminology.md`) |
