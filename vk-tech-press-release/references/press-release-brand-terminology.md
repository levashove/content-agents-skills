# Терминология: дополнения для пресс-релизов

Дополняет `references/brand-terminology.md`.

## Продукты VK Tech в пресс-релизе

Имена продуктов — по таблице продуктовых названий (`common/brand-terminology`, генерируется
из `naming:` продуктовых скиллов). Линейки без продуктового скилла (ещё не заведённые в
«products» (внутренний материал системы, в эту выгрузку не входит)) пишутся по редстандарту компании — он подаётся автору и контролёру
релиза; пустых догадок по аналогии с соседними именами не делать.
