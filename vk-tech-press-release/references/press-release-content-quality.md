# Качество контента: дополнения для пресс-релизов

Дополняет `references/content-quality.md`.

## Голос пресс-релиза

- Деловой, но читаемый. Фактологический. Конкретный
- Короткие абзацы (3–5 предложений), одна мысль — один абзац
- Факты в начале, детали в конце
- Конкретные цифры вместо оценочных наречий (банк стоп-слов — редстандарт)
- Активный залог: «VK Tech запустил», не «был запущен сервис»; род VK Tech — мужской

## Дополнительные запрещённые слова

Сверх банка редстандарта («значительно», «существенно», «в настоящее время» — уже там): не имеющий аналогов, лучший на рынке, производит реализацию, спешим сообщить, с гордостью представляем, вашему вниманию, в разы, в целом.

## Дополнительные замены

| Клише | Замена |
|-------|--------|
| инновационное решение | решение для [конкретная задача] |
| SMB / СМБ-сегмент | средний и малый бизнес |
| as-is | без переписывания кода |
| on-prem / on-premise в прозе | в контуре заказчика, на серверах заказчика |
| PAYG / pay-as-you-go | оплата только за использованные ресурсы |
| time-to-market | срок вывода продукта на рынок |
| managed-сервис | управляемый сервис |

(«в разы эффективнее», «анонсировала запуск» — в общей таблице замен редстандарта.)

## Факты (PR)

- Цифры продукта — из скилла продукта и фактуры заказчика: одно консервативное число с базой сравнения или «по оценке VK Tech». Диапазоны и оценки без базы не публикуются
- Аналитическая цифра — не больше одной на релиз, только в цитате и с источником внутри цитаты; в лиде и в теле продуктового релиза рыночных цифр нет (канон — `press-release-standards.md` → «Бюджеты объёма и цифр»)
- Партнёрский релиз, меморандум, обновление продукта могут выходить без цифр — суть в самом факте
- Если данных нет — запроси у пользователя; не добирай статистику «для веса»
