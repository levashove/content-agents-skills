# Поиск новостей для @sandyq_orda

Методика для ресёрчера дайджеста (направление «Казахстан», тег `kz`) и для работы
в чате без конвейера: как собрать шорт-лист инфоповодов, из которого редактор
канала делает одиночные новости и дайджест недели (рубрики 1–2 профиля
`references/sandyq-orda-channel.md`).

## Окно и объём

- **Одиночная новость:** окно — последние 72 часа; канал публикует новость в
  день выхода или на следующий будний день. Старше трёх суток — только если
  вышло развитие (новые цифры, решение, запуск).
- **Дайджест недели:** окно — понедельник — пятница прошлой недели плюс выходные;
  нужно 6–8 кандидатов, в дайджест идут 3–5.
- **Подборка мероприятий:** события следующего месяца, собирать в последнюю неделю
  текущего.

## Порядок поиска

1. **Фиды (без WebSearch).** `python3 «fetch_feeds» (внутренняя автопроверка репозитория, в чате недоступна — проверь этот пункт вручную) --tag kz --start
   <дата> --end <дата>` — шесть изданий с проверенным RSS (Profit.kz, Kapital.kz,
   Kursiv Media, DigitalBusiness.kz, The Tech, Bluescreen.kz). В конвейере дайджеста
   это делает действие `prefetch_feeds`.
2. **Первоисточники P1** — пресс-центры МИИЦР, правительства, Акорды и Astana Hub
   за окно: то, что там есть, идёт со ссылкой на первоисточник.
3. **WebSearch по подтегам** — запросы ниже; первый запрос простой, уточняющие — с
   одним оператором (`site:`, кавычки или дата).
4. **Анти-повтор.** Сверить шорт-лист с последними 30 постами канала

## Критерии отбора

Новость берётся в шорт-лист, если выполнены все три условия:

1. **Казахстан или регион с казахстанским участием** — компания, госорган, проект,
   рейтинг страны; мировые новости — только с местным следствием (визит, запуск в
   РК, сравнение со страной).
2. **B2B или B2G** — меняет что-то для бизнеса, госсектора, ИТ-рынка или
   ИТ-специалистов. Потребительская новость (новая функция Kaspi, цены на связь)
   проходит, если затрагивает рынок или регулирование.
3. **Есть проверяемый факт** — цифра, дата, сумма, срок, название документа или
   компании. «Планируется рассмотреть возможность» без срока и суммы — не новость.

**Приоритет при равенстве:** регулирование и законы с датой вступления в силу →
запуски госуслуг и платформ → крупные сделки и инвестиции с суммой → ИИ-проекты
с внедрением (не меморандум) → рейтинги и исследования → мероприятия.

**Не брать:** политические новости без цифровой составляющей; слухи и анонимные
источники; пресс-релизы вендоров без независимого подтверждения (кроме
партнёрских публикаций с меткой); новости конкурентов VK Cloud в формате их
рекламы (запуск продукта конкурента — только как рыночный факт, без оценок).

## Проверка

- Ссылка — на первоисточник (gov.kz, primeminister.kz, сайт компании) там, где он
  есть; издание — когда первоисточника нет или новость — эксклюзив издания.
- Дата публикации первоисточника — в окне; дату события и дату новости не путать.
- Цифры и суммы — дословно из источника, с валютой источника (тенге / доллары).
- Названия ведомств — актуальные на дату новости (МИИЦР с 2025 года; в документах
  до реорганизации — МЦРИАП).
- Две новости об одном событии из разных изданий — одна новость, ссылка на
  первоисточник или на самый полный текст.

## Формат шорт-листа

Для каждого кандидата:

```
N. [Подтег] Заголовок-факт с цифрой (как в канале)
   Источник: <название> — <URL> — <дата публикации>
   Факт: 1–2 предложения с цифрами и сроками из источника
   Почему для канала: что меняется для B2B/B2G
   Рубрика: новость / дайджест / мероприятия; приоритет 1–3
```

После списка — «Статус поиска»: окно, сколько запросов, какие подтеги не дали
новостей, какие P1-источники не ответили.
